# SadakYatra App - UX Flows

## 1. Customer Booking Flow
1. Splash -> select language (EN/HIN optional)
2. OTP login
3. Home: quick options (Local, Outstation, Airport, Wedding)
4. Enter pickup/drop/date-time/car category
5. See estimate and inclusions/exclusions
6. Confirm booking request
7. Booking status screen with timeline and support actions

## 2. Admin Ops Flow
1. Login -> dashboard
2. New booking list sorted by time
3. Open booking -> verify route/fare -> assign driver + vehicle
4. Confirm booking
5. Monitor ongoing trips
6. Resolve cancellations and close completed bookings

## 3. Driver Flow
1. Login
2. Assigned bookings list
3. Accept booking
4. Navigate to pickup (deep-link map)
5. Start trip
6. End trip
7. Mark payment mode + notes

## 4. Key UX Principles
- Minimum typing, maximum presets.
- One primary CTA per screen.
- Trust-forward UI: driver details, fare transparency, support access.
- Always show booking state clearly.

## 5. Required Screens (MVP)
- Auth: OTP login
- Home
- Create Booking
- Fare Estimate
- Booking Detail + Status Timeline
- My Bookings
- Profile + Help
- Admin: Dashboard, Booking Detail, Assignment
- Driver: Assigned Trips, Trip Detail
